Landing page para publicitar monitorías privadas de Álgebra Lineal.

## 🚀 Despliegue en GitHub Pages

### Pasos:

1. **Crear repositorio en GitHub:**
   - Ve a [github.com/new](https://github.com/new)
   - Nombre: `monitorias-algebra`
   - Público ✅
   - No inicializar con README

2. **Subir archivos:**
   ```bash
   cd monitorias-algebra
   git init
   git add .
   git commit -m "🚀 Landing page monitorías"
   git branch -M main
   git remote add origin https://github.com/ivanmezaf-wq/monitorias-algebra.git
   git push -u origin main
   ```

3. **Activar GitHub Pages:**
   - Ve a Settings → Pages
   - Source: `Deploy from a branch`
   - Branch: `main` / `/ (root)`
   - Click "Save"

4. **¡Listo!** Tu página estará en:
   ```
   https://ivanmezaf-wq.github.io/monitorias-algebra/
   ```
